# 访问边界与禁区

本文是本仓库的**硬约束清单**。任何改动若与本文冲突，以本文为准。

## 1. 系统与文件系统边界

### 允许（本仓库范围内）
- `/home/alice/projects/llm-lab-portal` —— 本仓库的开发工作树，属主 `alice`，目录权限 `0750`。
- 在 `alice` 账户下进行的**非生产**开发、构建、本地测试。

### 禁止（本仓库一律不碰）
| 路径 / 对象 | 说明 |
|---|---|
| `/srv/llm-lab/portal` | 未来正式部署点。**本仓库不创建、不预置**，仅在文档中约定 |
| `/opt/strata` | 既有 Strata 服务，由其他归属方维护 |
| `/home/bob` | 其他用户家目录 |
| `/home/carol` | 其他用户家目录 |
| 其他 Linux 用户 / 组 / sudoers | 不新增、不修改 |
| SSH 配置（`sshd_config`、`authorized_keys`） | 不新增、不修改 |
| Fleet 配置与绑定关系 | 不修改 |
| systemd 单元（system / user） | 不新增、不修改、不 enable |
| Caddy 站点与证书 | 不新增、不修改 |
| GPU 驱动 / 调度配置 | 不触碰 |

**开发工作树的创建方式有约束**：只创建 `/home/alice/projects/llm-lab-portal`
这一个目录（及其缺失的父目录 `~/projects`），**不改动 `/home/alice` 下任何既有目录**
（如 `vision-cutover-staging-*`、`下载`、`公共` 等）。

## 2. 身份与凭据边界

### 2.1 三类凭据互不共用（核心约束）

| 凭据 | 决定什么 | 不得用于 |
|---|---|---|
| **飞书 SSO** | 你是谁（身份） | 不得当作 API Token 使用；不得用于 Endpoint 授权判定 |
| **访问 Token** | 你持有什么凭据（凭证） | 不得替代 SSO 身份；不得承载 RBAC 语义 |
| **Endpoint RBAC** | 你能调哪个端点（授权） | 不得承担身份认证；不得与 SSO/Token 共享密钥材料 |

推论（必须成立的不变量）：
- 任一方密钥轮换，**不影响**另两方的有效性。
- 任一方泄露，**不导致**另两方被冒充或失效。
- 三者的存储位置、注入方式、失效范围相互独立。

### 2.2 凭据处理规则
- 凭据只存在于服务端运行时的注入环境（环境变量 / 密钥管理），**不进入 Git**。
- 前端不得内嵌密钥。前端可见即公开。
- 不在日志、错误信息、构建产物、原型 HTML 中回显凭据。
- 不读取、不复制、不转存其他用户或既有服务的私钥与 Token。

## 3. 数据边界

### 禁止入库
- 真实 `usage.jsonl` 及任何真实用量导出；
- 真实 prompt / completion 原文、对话与 session 记录；
- 用户上传或生成的图片、截图、附件；
- 数据库文件、日志文件；
- 任何真实 API Key / Token / 私钥 / `.env` 实际值。

`.gitignore` 覆盖上述形态，但它是**兜底而非许可**：不确定就不要 `git add`。
若发现已误提交，视为**安全事故**处理（轮换凭据 + 清理历史），而不是「下次注意」。

### 允许入库
- 文档（`README.md`、`docs/**`）；
- 原型 HTML / 静态资源（`prototypes/**`，不得含真实数据或密钥）；
- 团队自写的**脱敏合成**样本数据（须在文件中显式标注为合成）。

## 4. 网络与对外边界

- 不开放新的对外监听端口、不新建反向代理规则、不做端口转发 / 隧道。
- 不申请、不安装证书；不使用私有 CA 之外的自签方案。
- 不为了「先跑起来」临时降低 TLS 要求。

## 5. 与既有仓库的边界

- 本仓库与 `ProfessorZhi/llm-lab` 是**并列关系**：不整库搬运、不合并 legacy 分支、
  不继承其提交历史。
- **禁止**对既有 `ProfessorZhi/llm-lab` 的 `main` 分支或任何生产分支做写操作。
- 不绕行任何关于代码原始字节跨境转运的安全拦截。若 GitHub 写入被安全策略拦截，
  **立即停止并上报**，不换方式重试。

## 6. 部署与进程边界

- 本仓库不启动任何常驻服务或后台进程。
- 本仓库不创建 systemd 单元、不注册定时任务。
- 「让服务跑起来」属于部署流程，需要独立授权，不属于本仓库的初始化范围。
