本页使用此前会话及 AtlasStudio HTML 中提供的 28 行汇总数据，未重新下载或独立核验2027年度官方原始职位表。校验通过仅表示加总一致，不代表各项数据已获官方认证。页面为离线数据快照，不是实时招录网站。

三个方向是业务分析分组，不是官方机构分类。全国同系统地方单位合并；海关含缉私；边检仅包含出入境边防检查总站，移民管理其他机构另计。“中央党群机关”和“其他部委及未单列机构”等是归集类别，不能当作独立部门。部分小类拆分待复核。

人数和职位数分开统计；每岗招录 = 人数 ÷ 职位数；占比差 = 全国人数占比 − 全国职位占比，单位为百分点。筛选或排除税务后，结构图与集中度以当前范围重新计算，全国占比与右侧环形图保持全国分母。集中度基于这 28 个汇总类别的粒度；不能推断报考难度、竞争比或录取概率。
