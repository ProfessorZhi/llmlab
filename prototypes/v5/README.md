# Prototype v5 —— Data Atlas

## 1. 这是什么

Data Atlas 是 Portal 的**交互与数据呈现原型**：把 Lab 的模型端点、用量、配额与健康度
组织成一张可浏览的「地图」，用于在实现后端之前先固化信息架构与交互。

本目录只放原型资产。原型**不代表**已实现的功能，也不接入真实数据。

## 2. 关于 `dell_llm_lab_atelier_v5_data_atlas.html`

此处**如实记录事实状态**：

- 该 HTML 此前由 ChatGPT 生成，**目前存在于 ChatGPT 的项目 / 会话附件中**，
  **不在这台机器本地**，也不在本仓库中。
- 因此本仓库**没有**提交该文件。**不要**假定它已经入库，也**不要**凭空重写一个
  声称是它的 HTML——那会造成「文件已提交」的假象。

### 约定
- 若日后把该原型纳入版本管理，**约定路径为**：

  ```
  prototypes/v5/index.html
  ```

- 落地时必须先获得该文件的**实际内容**（从 ChatGPT 会话导出 / 附件下载），
  再以真实字节提交，并在提交信息中注明来源与获得方式。
- 在获得真实文件之前，本目录不放置任何占位 HTML，避免混淆。

## 3. 数据文件如何进入开发工作树（未来）

原型若需真实结构的样本，遵循：

1. **脱敏合成**样本可直接入库，但文件内须显式标注为合成数据。
2. **真实**数据（`usage.jsonl`、prompt、图片等）**永不入库**（见根 `.gitignore` 与
   `docs/access-boundaries.md`）。
3. 真实文件如需传送到开发工作树，走**显式的、带来源与去向记录**的传输动作，
   由人工确认，而不是随手 `scp` 或 `git add`。

## 4. 边界

- 原型 HTML / 静态资源允许入库（见根 `.gitignore` 的显式例外）。
- 原型中**不得**内嵌真实 API Key、Token、真实用量数据、真实 prompt 或用户图片。
- 原型不启动服务、不监听端口、不发起跨域请求到生产。
