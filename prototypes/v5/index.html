实体部署安全流程

平台不从 Web 按钮直接执行系统命令，更不会在后台替换运行中的他人模型服务。

  1. 01
    Deployment Profile

    模型版本、引擎、显存预算和协议能力。

  2. 02
    Preflight / Dry-run

    检查 NVML、资源占用、维护窗口与备份。

  3. 03
    管理员审批

    申请与实际执行分离；保留审计。

  4. 04
    执行 / Canary / 回滚

    仅在专门授权维护任务中执行。
